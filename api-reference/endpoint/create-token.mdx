---
title: 'Create API Token'
openapi: 'POST /api/v1/auth/tokens/'
---

Create a personal API key (`suk_…`) for the logged-in user. Studio session only.

<Info>
A personal key acts **as you** and can never do more than you can — if you lose access to a
project, so does the key. For integrations that should not depend on a person, use a
[service account](/api-reference/endpoint/create-service-account).
</Info>

## Request Body

- `name` (string, required): Token name/description
- `project` (string, optional): Project UUID to bind the key to — recommended. A bound key needs no `Sophy-Project` header and is refused on any other project
- `organization` (string, optional): Organization UUID to limit the key to. Implied by `project`
- `scopes` (array of strings, optional): Limit the key to these permissions (see [Permissions](/api-reference/endpoint/get-permissions)). Empty = your own permissions
- `expires_at` (string, optional): ISO 8601 expiration date (null = unlimited)

## Response

`201` with the key **and its secret**:

```json
{
  "token": "suk_...",
  "id": "uuid",
  "name": "My Production Token",
  "type": "user",
  "prefix": "suk_Ab12cd34",
  "user_id": "1",
  "service_account_id": null,
  "organization": "uuid",
  "project": "uuid",
  "scopes": ["calls:read"],
  "is_active": true,
  "revoked_at": null,
  "expires_at": "2026-12-31T23:59:59Z",
  "last_used_at": null,
  "is_expired": false,
  "is_valid": true,
  "created_at": "2026-04-20T10:35:00Z",
  "updated_at": "2026-04-20T10:35:00Z"
}
```

<Warning>
`token` is returned **only here**. Sophy stores a hash of it, so it cannot be shown again — copy
it now. Later reads show `prefix` to help you recognise the key.
</Warning>
