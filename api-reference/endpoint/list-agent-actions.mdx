---
title: 'List Agent Actions'
openapi: 'GET /api/v1/actions/'
---

List the business records your agents produced during conversations — contact requests, orders, support tickets, appointment requests — newest first. The project comes from the `Sophy-Project` header, or from the API key when the key is bound to a project. Requires the `actions:read` permission.

An action has two independent states:

- `status` is the business lifecycle, advanced by your team: `new` → `in_progress` → `done` | `cancelled`
- `steps` are the integrations that ran for it (e.g. the notification email), each `ok`, `skipped` or `error`. `needs_retry` is `true` when a step failed

## Query Parameters

- `type` (string): Action type, e.g. `contact_request`
- `status` (string): `new`, `in_progress`, `done` or `cancelled`
- `needs_retry` (boolean): Only actions with a failed step
- `agent_id` (string): Only actions of this agent
- `date_from`, `date_to` (datetime): Creation time range (ISO 8601)
- `offset` (integer): Number of items to skip (default 0)
- `limit` (integer): Max results to return (default 100, max 1000)

## Example

```bash
curl -X GET "https://platform-api.sophy.co/api/v1/actions/?type=contact_request&needs_retry=true" \
  -H "Authorization: Bearer suk_..." \
  -H "Sophy-Project: {project_id}"
```
