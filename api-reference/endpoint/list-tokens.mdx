---
title: 'List API Tokens'
openapi: 'GET /api/v1/auth/tokens/'
---

List the logged-in user's personal API keys, newest first, 20 per page. Revoked keys are included
(`is_active: false`). The secret is never part of this response.

## Response

```json
{
  "count": 1,
  "next": null,
  "previous": null,
  "results": [
    {
      "id": "uuid",
      "name": "string",
      "type": "user",
      "prefix": "suk_Ab12cd34",
      "user_id": "1",
      "service_account_id": null,
      "organization": "uuid",
      "project": "uuid",
      "scopes": [],
      "is_active": true,
      "revoked_at": null,
      "expires_at": null,
      "last_used_at": "2026-04-20T10:30:00Z",
      "is_expired": false,
      "is_valid": true,
      "created_at": "2026-04-20T09:00:00Z",
      "updated_at": "2026-04-20T09:00:00Z"
    }
  ]
}
```

- `prefix`: First characters of the secret, to recognise the key
- `scopes`: Permissions the key is limited to; empty = the owner's permissions
- `last_used_at`: Updated at most once a minute
