---
title: 'Create Service Account'
openapi: 'POST /api/v1/organizations/{organization_id}/service-accounts/'
---

Send `name`, optional `description`, optional `project` (restricts the account to one project) and `permissions` (see [Permissions](/api-reference/endpoint/get-permissions)). You can only grant permissions you hold; a project-restricted account only gets project permissions. Keys of the account keep working when the person who created it leaves. Needs `keys:manage`.
