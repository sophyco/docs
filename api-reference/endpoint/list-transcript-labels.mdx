---
title: 'List Project Labels'
openapi: 'get /api/v1/transcripts/labels/'
---

Returns all unique labels used across transcripts in a project, sorted alphabetically. Use this for autocomplete when adding labels to a transcript. The project comes from the `Sophy-Project` header, or from the API key when the key is bound to a project.

## Response

```json
{
  "labels": ["Bilgi Talebi", "Şikayet", "VIP"]
}
```

## Notes

- Labels are derived from existing transcripts — no predefined list is maintained.
- To filter transcripts by a label, use `GET /api/v1/transcripts/?label=VIP`.
- To set labels on a transcript, use `PATCH /api/v1/transcripts/{transcript_id}/labels/`.

## Example

```bash
curl https://platform-api.sophy.co/api/v1/transcripts/labels/ \
  -H "Authorization: Bearer suk_..." \
  -H "Sophy-Project: {project_id}"
```
