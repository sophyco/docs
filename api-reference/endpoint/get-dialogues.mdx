---
title: 'List Dialogues'
openapi: 'GET /api/transcripts/{project_id}/dialogues/'
---

Retrieve the individual messages (dialogues) of a conversation, with optional filtering and pagination.

## Path Parameters

- `project_id` (string, required): Project UUID

## Query Parameters

- `conversationID` (string, **required**): Conversation ID. Omitting it returns `400`.
- `sessionID` (string): Filter by session ID
- `role` (string): Filter by role (see below)
- `format` (string): Filter by format (`launch`, `request`, `trace`, `result`)
- `type` (string): Filter by type (see below)
- `status` (string): Filter by status (`pending`, `processing`, `completed`, `cancelled`)
- `offset` (integer): Number of items to skip (default `0`)
- `limit` (integer): Max results to return (default `100`, max `1000`)

## Response

Returns a paginated object. The dialogues are in `results`, ordered by `startTime` descending (newest first).

  "count": 42,

  "limit": 100,

<Note>
The internal `payload` field (platform message IDs and raw provider payloads) is
not exposed by this endpoint.
</Note>

## Filter Values

### role
- `user` — Customer/user message
- `assistant` — AI assistant message
- `human` — Human agent message
- `system` — System message
- `developer` — Injected developer/context message
- `reasoning` — Model reasoning step
- `tool_call` — Tool/function call made by the agent

### format
- `launch` — Conversation launch
- `request` — Inbound request
- `trace` — Intermediate trace
- `result` — Final result

### type
- `text` — Text message
- `image` — Image message
- `video` — Video message
- `choice` — Quick reply / choice
- `action` — Action trigger
- `launch` — Launch event
- `flow` — Flow step
- `block` — Block step
- `request` — Request event
- `debug` — Debug information

### status
- `pending` — Waiting to process
- `processing` — Currently processing
- `completed` — Successfully completed
- `cancelled` — Cancelled/failed

## Examples

```bash
# All dialogues of a conversation
curl -X GET "https://platform-api.sophy.co/api/transcripts/{project_id}/dialogues/?conversationID={conversation_id}" \
  -H "Authorization: Bearer suk_..."

# Completed messages only
curl -X GET "https://platform-api.sophy.co/api/transcripts/{project_id}/dialogues/?conversationID={conversation_id}&status=completed" \
  -H "Authorization: Bearer suk_..."

# User messages only
curl -X GET "https://platform-api.sophy.co/api/transcripts/{project_id}/dialogues/?conversationID={conversation_id}&role=user" \
  -H "Authorization: Bearer suk_..."

# Second page of 50
curl -X GET "https://platform-api.sophy.co/api/transcripts/{project_id}/dialogues/?conversationID={conversation_id}&offset=50&limit=50" \
  -H "Authorization: Bearer suk_..."
```
