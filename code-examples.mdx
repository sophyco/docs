# Code Examples

Every example below talks to production. Swap `BASE_URL` to target another environment:

| Environment | Base URL |
| --- | --- |
| Production | `https://platform-api.sophy.co` |
| Test | `https://test-platform-api.sophy.co` |
| Local | `http://localhost:8000` |

Project-scoped endpoints (`/api/v1/…`) take the project from the `Sophy-Project` header. An API key bound to a project carries its project, so the header can be left out.

## Python

```bash
pip install requests
```

### Basic Usage

```python
import requests

TOKEN = "suk_..."
PROJECT_ID = "be02a6b2-0061-4849-983b-26504bde1144"

    "Sophy-Project": PROJECT_ID,
}

# Get transcripts

```

### Login

```python
import requests

BASE_URL = "https://platform-api.sophy.co"

login_data = {
    "username": "sophyadmin",
    "password": "password123"
}

response = requests.post(f"{BASE_URL}/api/auth/login/", json=login_data)

if response.status_code == 200:
    token = response.json()["token"]
    print(f"Token: {token}")
else:
    print(f"Login failed: {response.json()}")
```

### Create New Token

```python
import requests

TOKEN = "suk_..."
BASE_URL = "https://platform-api.sophy.co"

headers = {"Authorization": f"Bearer {TOKEN}"}

token_data = {
    "type": "service",
    "name": "Batch Processing",
    "expires_at": "2026-12-31T23:59:59Z"
}

response = requests.post(f"{BASE_URL}/api/auth/tokens/", json=token_data, headers=headers)

new_token = response.json()
print(f"Created token: {new_token['token']}")
```

### Batch Processing

List endpoints return a page (`count`, `offset`, `limit`, `results`). Walk `offset` until you have `count` items.

```python
import requests

TOKEN = "suk_..."
PROJECT_ID = "be02a6b2-0061-4849-983b-26504bde1144"
BASE_URL = "https://platform-api.sophy.co"

headers = {"Authorization": f"Bearer {TOKEN}", "Sophy-Project": PROJECT_ID}

def fetch_all_dialogues(conversation_id, limit=500):
    """Fetch every dialogue of one conversation, page by page."""
    offset, dialogues = 0, []
    while True:
        response = requests.get(
            f"{BASE_URL}/api/v1/transcripts/dialogues/",
            headers=headers,
            params={"conversationID": conversation_id, "offset": offset, "limit": limit},
        )
        response.raise_for_status()
        page = response.json()
        dialogues.extend(page["results"])
        offset += limit
        if offset >= page["count"]:
            return dialogues

for dialogue in fetch_all_dialogues("conversation-id"):
    if dialogue["role"] == "user":
        print(f"User message: {dialogue['message']}")
    elif dialogue["role"] == "assistant":
        print(f"AI response: {dialogue['message']}")
```

## JavaScript / Node.js

```bash
npm install axios
```

### Basic Usage

```javascript
const axios = require('axios');

const TOKEN = "suk_...";
const PROJECT_ID = "be02a6b2-0061-4849-983b-26504bde1144";
const BASE_URL = "https://platform-api.sophy.co";

  "Sophy-Project": PROJECT_ID
};
```

### Fetch with Filters

```javascript
const axios = require('axios');

const TOKEN = "suk_...";
const PROJECT_ID = "be02a6b2-0061-4849-983b-26504bde1144";
const BASE_URL = "https://platform-api.sophy.co";

const headers = { "Authorization": `Bearer ${TOKEN}`, "Sophy-Project": PROJECT_ID };

// Completed user messages of one conversation
axios.get(`${BASE_URL}/api/v1/transcripts/dialogues/`, {
  headers,
  params: { conversationID: "conversation-id", status: "completed", role: "user" }
})
  .then(res => {
    res.data.results.forEach(dialogue => {
      console.log(`${dialogue.role}: ${dialogue.message}`);
    });
  })
  .catch(err => console.error(err.response.data));
```

### Class-based Client

```javascript
class SophyAPIClient {
  constructor(token, projectId, baseUrl = "https://platform-api.sophy.co") {
    this.baseUrl = baseUrl;
    this.headers = {
      "Authorization": `Bearer ${token}`,
      "Content-Type": "application/json"
    };
    // Omit projectId when the API key is bound to a project.
    if (projectId) this.headers["Sophy-Project"] = projectId;
  }

  async getTranscripts(filters = {}) {
    try {
      const response = await axios.get(
        `${this.baseUrl}/api/v1/transcripts/`,
        { headers: this.headers, params: filters }
      );
      return response.data;
    } catch (error) {
      console.error("Error fetching transcripts:", error.response.data);
      throw error;
    }
  }

  async getDialogues(conversationId, filters = {}) {
    try {
      const response = await axios.get(
        `${this.baseUrl}/api/v1/transcripts/dialogues/`,
        { headers: this.headers, params: { conversationID: conversationId, ...filters } }
      );
      return response.data;
    } catch (error) {
      console.error("Error fetching dialogues:", error.response.data);
      throw error;
    }
  }

  async createToken(type, name, expiresAt = null) {
    try {
      const response = await axios.post(
        `${this.baseUrl}/api/auth/tokens/`,
        { type, name, expires_at: expiresAt },
        { headers: this.headers }
      );
      return response.data;
    } catch (error) {
      console.error("Error creating token:", error.response.data);
      throw error;
    }
  }
}

// Usage — pass a third argument to target test or local
const client = new SophyAPIClient("suk_...", "project-id");
client.getTranscripts({ platform: "whatsapp" })
  .then(page => console.log(page.results));
```

## cURL

```bash
BASE_URL="https://platform-api.sophy.co"   # or https://test-platform-api.sophy.co, http://localhost:8000
TOKEN="suk_..."
PROJECT_ID="be02a6b2-0061-4849-983b-26504bde1144"
```

### Login

```bash
curl -X POST ${BASE_URL}/api/auth/login/ \
  -H "Content-Type: application/json" \
  -d '{
    "username": "sophyadmin",
    "password": "password123"
  }' | jq .token
```

### List Tokens

```bash
curl -X GET ${BASE_URL}/api/auth/tokens/ \
  -H "Authorization: Bearer ${TOKEN}" | jq .
```

### Create Token

```bash
curl -X POST ${BASE_URL}/api/auth/tokens/ \
  -H "Authorization: Bearer ${TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "service",
    "name": "Batch Job",
    "expires_at": "2026-12-31T23:59:59Z"
  }' | jq .token
```

### Get Transcripts

```bash
curl -X GET "${BASE_URL}/api/v1/transcripts/?platform=whatsapp" \
  -H "Authorization: Bearer ${TOKEN}" \
  -H "Sophy-Project: ${PROJECT_ID}" | jq .
```

### Get Dialogues

```bash
curl -X GET "${BASE_URL}/api/v1/transcripts/dialogues/?conversationID={conversation_id}&status=completed" \
  -H "Authorization: Bearer ${TOKEN}" \
  -H "Sophy-Project: ${PROJECT_ID}" | jq .
```

### Using jq for JSON parsing

```bash
# Pretty print
curl ... | jq .

# Select specific fields
curl ... | jq '.results[].message'

# Filter
curl ... | jq '.results[] | select(.status == "completed")'

# Map
curl ... | jq '.results | map({role: .role, message: .message})'
```
